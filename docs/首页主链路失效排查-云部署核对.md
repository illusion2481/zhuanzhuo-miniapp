# 首页/主链路"用不了"排查手册（云部署核对）

> 症状：首页按钮点了没反应 / 弹"调用失败" / 座位图不变色 / 列表空白。  
> 结论先行：**绝大多数这类"整页失效"不是代码 bug，而是云环境或云函数未就绪。**

---

## 0. 先说结论：三件事按这个顺序查，90% 的问题在这一步解决

| 优先级  | 检查项                  | 做完的效果        |
| ---- | -------------------- | ------------ |
| ⭐ 最高 | **云开发环境绑定**（见 §1）    | 所有云函数立刻能用    |
| 高    | **云函数是否已逐个上传**（见 §2） | 对应功能逐个恢复     |
| 中    | **首页依赖的云函数清单**（见 §3） | 知道哪个按钮对应哪个函数 |

---

## 1. [最高优先级] 云开发环境 ID 必须匹配你当前的环境

**这是"首页全用不了"的头号元凶。**

前端 `miniprogram/config/env.ts` 里写死了一个云环境 ID：

```ts
export const CLOUD_ENV_ID = 'cloudbase-d1gehjncwca809f8c';
```

**核对动作：**

1. 打开微信开发者工具 → 顶部「云开发」按钮 → 看左侧「环境管理」/「环境」里的**真实环境 ID**。
2. 如果开着**多个环境**（免费版 / 正式版），`callFunction` 会只打到指定那个 `cloudbase-d1gehjncwca8098c`。
3. 如果这个 ID 不是当前项目绑定的环境，**所有** `wx.cloud.callFunction` 直接失败 → 首页、列表、推荐全挂。

**修法（二选一）：**

- ✅ **推荐**：把 `CLOUD_ENV_ID` 改成你云开发面板里看到的**那个真实环境 ID**；或
- 改回 `undefined`（让开发者工具自动用当前选择的环境）：

```ts
export const CLOUD_ENV_ID = ''; // 留空 = 使用开发者工具当前选中的环境
```

> 📌 检查 `wx.cloud.init` 代码在 `miniprogram/app.ts:onLaunch`。若 `wx.cloud` 不存在或环境错，会直接 `return`，导致 `globalData.cloudReady` 保持 false，所有云函数不可用。

## 2. [高优先级] 云函数逐个核对是否「已部署」

首页及其主链路（选房→选座→预约→签到我预约）依赖这些云函数。**逐个在云开发面板确认「已部署」，缺一个就断一节。**

| 云函数                 | 负责的页面/按钮           | 没上传的后果                    |
| ------------------- | ------------------ | ------------------------- |
| `login`             | app 启动静默登录、个人页     | 无用户态，预约/记录全按"无身份"处理       |
| `seedData`          | 注入示例自习室/座位/偏好      | 列表空（但前端有 DEMO 兜底，仍能点通 UI） |
| `categoryList`      | 首页「座位偏好」chips      | 首页偏好显示"加载中…"实际失败          |
| `roomList`          | 自习室列表、座位图          | 选房/选座失败（会走 DEMO 兜底）       |
| `aiRecommend`       | 首页「智能推荐座位」「生成学习计划」 | 推荐/计划按钮 toast「AI 推荐失败」    |
| `createReservation` | 座位抽屉「立即预约」         | 下单报错                      |
| `studyRecord`       | 学习记录、我的预约列表        | 我的预约空白/失败                 |
| `checkin`           | 签到                 | 签到失败                      |
| `leaveSeat`         | 暂离/返回              | 暂离/返回失败                   |
| `expireRecords`     | 定时超时/爽约            | 座位状态不自动流转                 |
| `updateReservation` | 改约                 | 改时间失败                     |

**操作：** 微信开发者工具 →「云开发」→「云函数」→ 逐个**右键 → 上传并部署（云端安装依赖）**。新增的 `updateReservation` 记得也要传。

## 3. [极高优先级] 首页每个按钮 → 对应的云函数链

在首页点某个按钮失效，对应关系如下，方便你精确报错：

| 首页元素             | 走到的云函数                                  | 无它就……       |
| ---------------- | --------------------------------------- | ----------- |
| 「浏览自习室」(goRooms) | `switchTab` 不调云；转到 rooms 页 → `roomList` | rooms 页空/失败 |
| 「学习记录」(goStudy)  | `switchTab` → study 页 → `studyRecord`   | 学习页加载失败     |
| AI 座位偏好 chips    | `categoryList`                          | 显示空偏好       |
| 「智能推荐座位」         | `aiRecommend`                           | 弹「AI 推荐失败」  |
| 「生成今晚学习计划」       | `aiRecommend` (action=generate_plan)    | 弹「生成计划失败」   |
| 推荐结果卡片点入         | `createReservation`                     | 预约失败        |
| 我的预约列表           | `studyRecord`(list_reservations)        | 列表空白        |

## 4. 前端已有的「降级」机制（别慌，没云端也不全崩）

项目已为**云端未就绪**加了三层兜底，列表/选座 UI **不会白屏**：

- `services/room.ts:listRooms`：**3 级降级** → `roomList` 云函数 → 云端 categories 组装 → 内置 `DEMO_ROOMS`（3 房 26 座演示数据）。**即使 roomList 没传，选房→选座→预约 UI 也能点通**（只是读的是演示数据）。
- `pages/home.ts:loadPreferences`：`categoryList` 失败**静默降级**为空数组，不崩。
- `pages/home.ts:onRecommend`：`aiRecommend` 失败 → 显示降级 toast「AI 未配置，已按偏好匹配」并走 fallback 出基础推荐。
- `pages/seats/loadSeats`：`listRooms` 失败 → toast「请先部署 roomList」，但页面结构仍在。

> 所以如果**连 UI 结构都显示不出来/白屏**，那几乎必然是 §1 的**云环境 ID 不匹配**或基础库/构建 npm 问题，而不是云函数没传。

## 5. 补充排查：不是云函数的几类"用不了"

| 现象                    | 排查                                                          |
| --------------------- | ----------------------------------------------------------- |
| 真机调试编译红屏/报找不到组件       | 先「工具 → 构建 npm → 清除缓存 → 全部清除 → 编译」                           |
| 点按钮完全无响应（连 toast 都没有） | 检查是否 `app.js` 白屏/`onLaunch` 抛错；看 console 是否报 `wx.cloud` 未定义 |
| 一键全白                  | IDE 基础库版本过旧，升到 ≥2.32（云开发常见需要）                               |

## 以」首页为例的 3 分钟自测命令

1. 微信开发者工具 →「云开发」→ 顶部环境 ID 与 `config/env.ts:CLOUD_ENV_ID`（或留空）一致。
2. 「云函数」列表里确认下面这些都有「运行中/已部署」：`login` `seedData` `categoryList` `roomList` `aiRecommend` `createReservation` `checkin` `studyRecord` `leaveSeat` `expireRecords` `updateReservation`。
3. 「数据库」里看到集合 `users` `categories` `records`（有 seedData 数据更好）。

上面三步都满足，首页各项功能应能正常；若仍失效，请把**控制台红色报错原文**发回，我来精准定位。
