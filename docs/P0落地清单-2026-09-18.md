## P0-1 实时座位同步（云开发 watch 替代 15s 轮询）

### 为什么不能直接 watch records
`records` 集合生产环境读权限收紧为 `doc.user_id == auth.openid`（DEPLOY.md §6），前端**只能 watch 到自己的记录**，别人的预约/取消/签到变化收不到。

### 方案：房间文档「版本戳 + watch」
| 层 | 动作 |
|---|---|
| 云端 | 新增 `cloudfunctions/shared/presence.js`：`bumpPresenceVersion(roomId)` 更新 `categories.doc(roomId)` 的 `updated_at + presence:{version,at}`，失败静默（只做实时提速，不阻塞业务） |
| 云端 | 同步 `presence.js` 到 6 个写操作云函数的 shared/：`createReservation / cancelReservation / checkin / leaveSeat / expireRecords / updateReservation` |
| 云端 | 各云函数在**占用状态变更落库成功后**调用 bump（createReservation 两条路径、leaveSeat 暂离/返回两个分支、expireRecords 收集 affectedRooms 后批量 bump） |
| 前端 | `pages/seats/seats.ts` 新增 `startWatch()`：`wx.cloud.database().collection('categories').doc(roomId).watch({ onChange: 静默重拉 roomList, onError: 降级 })` |
| 前端 | onShow/onLoad 建 watch，onHide/onUnload 销毁；**15s 轮询保留为兜底**（watch 断连/低版本基础库不退化） |

### 一致性保证
- 座位占用**仍由 roomList 唯一权威源**计算，watch 只是「快进键」→ 不引入第二套占用口径，天然守住报告 §4 红线。
- `adminSeatMaintain` 直接改 categories 文档本身 → watch 天然覆盖维护态开关。

### ⚠️ 部署前提
**categories 集合需「所有用户可读」**：watch 依赖前端可读该集合。DEPLOY.md 权限段只约束 records/users；请到云开发控制台确认 categories 的读权限为「所有用户可读」。（房间/座位属性是公开数据，不涉隐私。）

## P0-3 一键续时（active/paused 延长结束时间）

### 云端
- `cloudfunctions/updateReservation/index.js`：
  - SCHEMA 增 `extend_minutes { type:'number', min:15, max:240, optional:true }`。
  - 新增续时分支：**仅 `active / paused`** 可续时；`start_at` 不动，仅 `end_at += extend_minutes`；续时后**夹到房间打烊**（复用 `clampToOpenWindow`）、**复检时段冲突**（排除自身）；payload 打 `extended:true`；成功后 **bumpPresenceVersion**（前端即时刷新）。

### ⚠️ 关键坑（必须记住）
**validator 对 number 的 `min/max` 是「收敛（clamp）」而非「拒绝」**：请求 `extend_minutes:10` 会被**钳到 15** 而不是报错。这其实是合理设计（服务端防恶意短续时），但测试断言必须按 clamp 语义写，不能期望「拒绝」。

### 前端
- `services/record.ts`：新增 `extendReservation(recordId, minutes)`。
- `pages/myReservations/*`：
  - actions 增 `extend`，active 态操作区出现「续时」主按钮；
  - 新增 self-popup：选择 30 / 60 / 90 分钟 → 确认 → `extendReservation` → toast「已续时 N 分钟」→ 重载；
  - 样式：`.extend-option` 三列网格胶囊。

### 测试
- `scripts/cloud-logic.test.cjs` 增 7 个用例：续时成功（end_at 顺延、start 不动、extended 标记）、续时+改约互斥引用、pending_checkin 拒绝、10min→15min clamp、非本人拒绝。**297/297 全绿**。
